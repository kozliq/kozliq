### Наши правила

- **Бесплатно.** Без тарифов, пробных периодов и «премиума».
- **Без рекламы.** Ни баннеров, ни партнёрок, ни обязательных подписок на каналы.
- **Без водяных знаков.** Что скачал — то и получил.
- **Без регистрации.** Ни аккаунта, ни почты, ни телефона.
